## #1 OpenAI API
- Website: https://platform.openai.com
- Pricing: Paid
- Use it for: General-purpose GPT models for chat, tools, and vision
- In plain English: The ChatGPT brain you can plug into your own app or chatbot.

## #2 Anthropic API
- Website: https://claude.com/platform/api
- Pricing: Paid
- Use it for: Claude models, strong at coding and long context
- In plain English: Claude's brain for your own app. Great at writing, reasoning and long documents.

## #3 Google Gemini API
- Website: https://ai.google.dev
- Pricing: Freemium
- Use it for: Gemini models with large context and multimodal input
- In plain English: Google's AI with a generous free tier, good for chatbots and reading images or PDFs.

## #4 xAI API
- Website: https://x.ai/api
- Pricing: Paid
- Use it for: Grok models plus image, video and voice on one API key
- In plain English: Grok's AI for your own app. The same key also makes images, video and voice, and it can search the web and X live. Pay as you go, with a free playground to test before you buy.

## #5 DeepSeek API
- Website: https://api-docs.deepseek.com
- Pricing: Paid
- Use it for: Low-cost models with OpenAI- and Anthropic-compatible APIs
- In plain English: Very cheap AI for your own app, and it works with code written for OpenAI or Claude. Pay as you go with no free tier, and prices drop by half outside peak hours.

## #6 OpenRouter
- Website: https://openrouter.ai
- Pricing: Freemium
- Use it for: One API key to route across many model providers
- In plain English: One account to try many different AI models and pick the best price for your chatbot.

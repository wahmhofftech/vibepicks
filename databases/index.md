## #1 Supabase
- Website: https://supabase.com
- Pricing: Freemium
- Use it for: Postgres, auth, storage, and realtime in one backend
- In plain English: Stores your app's data plus log-ins and file uploads, all in one free-to-start package.

## #2 Firebase
- Website: https://firebase.google.com
- Pricing: Freemium
- Use it for: Realtime NoSQL backend for quick mobile/web apps
- In plain English: Google's all-in-one backend for saving data, great for phone apps and realtime updates.

## #3 Neon
- Website: https://neon.com
- Pricing: Freemium
- Use it for: Serverless Postgres with branching
- In plain English: A simple online database that's free to start and only charges when it's actually being used.

## #4 Convex
- Website: https://www.convex.dev
- Pricing: Freemium
- Use it for: Reactive TypeScript backend with built-in database
- In plain English: A backend where your app's data updates live on screen, without setting up servers.

## #5 PlanetScale
- Website: https://planetscale.com
- Pricing: Paid
- Use it for: Scalable managed MySQL/Postgres
- In plain English: A heavy-duty database for when your app gets lots of users and needs to stay fast.
